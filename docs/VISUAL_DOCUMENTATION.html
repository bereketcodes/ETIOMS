The Problem in Ethiopia

  • • Information Fragmentation: Notices are scattered across newspapers (Addis Zemen, The Ethiopian Herald), bulletin boards, and disconnected websites.
  • • Dense 50+ Page Documents: Procurement officers spend days manually digging through legal boilerplate, bid bond (CPO) clauses, and technical specs.
  • • Costly Disqualification: Submitting bids without meeting mandatory trade license renewal or years-of-experience requirements results in forfeiture of bid security.
  • • Missed Deadlines: Manual spreadsheet tracking across multiple bids leads to missed submission cut-offs.
✨

The ETIOMS Solution

  • ✓ Centralized Intelligence: Ingests notices and PDFs, providing multi-factor filtering by sector, region, and deadline.
  • ✓ AI Capability Matching (0–100%): Evaluates company credentials against tender demands with green contributing strengths and amber missing factor warnings.
  • ✓ Grounded RAG Q&A: Natural language dialogue powered by Gemini 3.6 Flash providing verifiable citations directly from tender document text.
  • ✓ 7-Stage Kanban Pipeline: Lifecycle tracking from Discovered to Awarded with stage notes and 7-day proximity deadline alerts.

Relational Database Model (SQLAlchemy)

ACID-compliant relational structure maintaining referential integrity across 7 key tables.

organization_profiles PK: id (GUID)
  • • company_name (String 255)
  • • sectors (JSON Array)
  • • operating_regions (JSON)
  • • years_experience (Integer)
  • • certifications (JSON)
  • • past_projects_summary (Text)
users PK: id (GUID)
  • • email (String unique)
  • • user_name (String)
  • • hashed_password (Bcrypt)
  • • organization_id (FK)
  • • role (Admin / Member)
  • • is_active (Boolean)
tenders PK: id (GUID)
  • • title (String 500)
  • • procuring_entity (String)
  • • sector & region (String)
  • • deadline (Date indexed)
  • • requirements (JSON)
  • • full_text (Text)
tender_matches PK: id (GUID)
  • • organization_id (FK)
  • • tender_id (FK)
  • • total_score (Float 0-100)
  • • compliance_decision (Str)
  • • ai_justification (Text)
  • • breakdown (JSON)
opportunity_tracking PK: id (GUID)
  • • organization_id (FK)
  • • tender_id (FK)
  • • status (7-Stage Enum)
  • • notes (Text proposal log)
  • • created_at (Timestamp)
  • • updated_at (Timestamp)
notifications PK: id (GUID)
  • • user_id (FK)
  • • type (Deadline / Match)
  • • message (Text alert)
  • • read_flag (Boolean)
  • • created_at (Timestamp)
